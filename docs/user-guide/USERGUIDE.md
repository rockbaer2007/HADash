# Benutzerhandbuch

1. In Home Assistant den Dashboard-Bearbeitungsmodus öffnen.
2. Über die drei Punkte den RAW-Konfigurationseditor öffnen.
3. Den vollständigen Code kopieren und als `<Name>.dash` speichern.
4. Die Datei in HADash öffnen.
5. Eine Ansicht auswählen und als TXT, YAML oder vollständiges Dashboard exportieren.

Alternativ können JSON- und YAML-Daten aus Backups direkt geöffnet werden.
