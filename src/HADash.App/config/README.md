# Portable Konfiguration

HADash erzeugt die persönliche Datei `user.config` beim ersten Start beziehungsweise beim Speichern der Einstellungen.

Die Datei wird bewusst nicht in Git eingecheckt, weil sie lokale Pfade, zuletzt geöffnete Dateien, Fensterpositionen und persönliche Einstellungen enthalten kann.
