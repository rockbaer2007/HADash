# Mitwirken an HADash

Danke für dein Interesse an HADash.

## Entwicklungsumgebung

- Windows 10 oder Windows 11
- Visual Studio 2022
- Workload **.NET-Desktopentwicklung**
- .NET 8 SDK
- .NET Framework 4.8 Developer Pack

## Vorgehen

1. Repository forken oder klonen.
2. Einen Branch erstellen, zum Beispiel `feature/dashboard-validator`.
3. Änderungen klein und nachvollziehbar halten.
4. Projekt in Visual Studio bauen und die betroffenen Funktionen testen.
5. Pull Request mit einer kurzen Beschreibung und Testhinweisen erstellen.

## Stil

- Benutzeroberfläche auf Deutsch, Englisch und Französisch berücksichtigen.
- Portable Speicherung im Programmordner beibehalten.
- Themewechsel darf keine Dashboarddatei erneut einlesen oder parsen.
- Neue Einstellungsbereiche in die modulare Settings-Struktur einfügen.
- Keine persönlichen Dashboarddaten oder Pfade committen.

## Fehler melden

Bitte nenne:

- HADash-Version
- Windows-Version
- verwendetes Dateiformat
- genaue Fehlermeldung
- Schritte zur Reproduktion
